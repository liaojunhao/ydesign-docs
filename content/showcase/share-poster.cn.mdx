用 HTML 或 React JSX 写一张 1200×630（或自定义尺寸）的模板，把标题、封面、用户名做成变量。用户点「分享」时调用图片 API 即可出图。

常见流程：

1. 海报版式只设计一次。
2. 渲染时传入 `{ title, cover, user }`。
3. 把 PNG/JPEG 地址写进分享卡片。
