Write a 1200×630 (or custom) template in HTML or React JSX. Bind the title, cover image, and user name as variables, then call the Image API whenever someone hits Share.

Typical flow:

1. Design the poster once as a template.
2. Pass `{ title, cover, user }` at render time.
3. Cache the PNG/JPEG URL on the share payload.
