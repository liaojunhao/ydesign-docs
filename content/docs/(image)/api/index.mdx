OpenAPI playground is an interactive panel generated from an OpenAPI spec. It shows parameters, request body, example code, and a **Send** button that actually calls the API.

This demo uses [JSONPlaceholder](https://jsonplaceholder.typicode.com/) because it allows browser CORS. The site is statically exported, so there is no `/api/proxy` — the playground talks to the public server directly.

<Callout title="Try it">
  Open **Get a post**, keep `id` as `1`, then click Send. You should see JSON for the first post.
</Callout>
