---
title: Templates
description: Design an image with HTML or React JSX
---

A template is a layout file. You can write it as HTML or React JSX; the renderer fills in variables and exports a PNG or JPEG.

```jsx
export default function Poster({ title, cover }) {
  return (
    <div className="relative h-[630px] w-[1200px] bg-black text-white">
      <img src={cover} alt="" className="absolute inset-0 size-full object-cover opacity-40" />
      <h1 className="relative p-16 text-6xl font-semibold">{title}</h1>
    </div>
  );
}
```

The same template can be opened in the **Editor** if you want to tweak it visually instead of in code.
