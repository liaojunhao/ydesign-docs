Use HTML or React JSX to design a template, bind variables, then call the API to get a high-quality image. Typical uses: share posters, product covers, article covers, and marketing creatives.

This is the default docs tree — the URL stays at `/docs`. Switch to **Editor** in the sidebar to open the visual template editor at `/docs/editor`.
