title: Templates
description: Open and edit the same templates the API renders
---

Templates you design here are stored as HTML / JSX and can be rendered by the Image API.

1. Open a template from the library, or duplicate one.
2. Bind a layer to a variable (for example `title`).
3. Save. The API can now render it with different data.

This page also exists under Image API. Use the product dropdown to jump to the code-first template guide without leaving "Templates".
