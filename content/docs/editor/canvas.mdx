---
title: Canvas
description: Arrange layers on the artboard
---

The canvas is an infinite artboard. Drag text, images, and shapes; snap to guides; preview at export size (for example 1200×630 for a share card).

Keyboard shortcuts:

| Shortcut | Action |
| --- | --- |
| `V` | Select |
| `T` | Text |
| `⌘Z` | Undo |

This page only exists in the Editor. Switching to Image API from here opens the Image API home.
