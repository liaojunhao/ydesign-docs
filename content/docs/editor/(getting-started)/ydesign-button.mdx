**ydesign Button** embeds the editor into any website with one script. A button opens the editor in a dialog, so people can design inside your app.

The script is [https://static.yitu-design.com/button-v1.js](https://static.yitu-design.com/button-v1.js). It opens `https://yitu-design.com/studio` and sends the export back to the page with `postMessage`.

## Why use the ydesign button?

1. **Easier designing:** The ydesign UI lets people who are not design-tool experts make a complete design. Put the button in your app and they can start there.
2. **Light integration:** You do not rebuild an editor. Add the script and a button.
3. **No extra design tool:** People finish the design on your site instead of leaving for another platform.
4. **More time on site:** Creating and editing designs in place keeps people in your product longer.

## How to integrate

1. Add the script.

```html
<script src="https://static.yitu-design.com/button-v1.js"></script>
```

2. Add a button.

```html
<button id="ydesign-button">Open editor</button>
```

3. Call `createYdesignEditor` on click.

```html
<script>
  const button = document.getElementById('ydesign-button');
  button.addEventListener('click', () => {
    window.createYdesignEditor({
      // create your own license key at https://ydesign.com/cabinet/
      key: 'YOUR_LICENSE_KEY',
      onPublish: ({ dataURL, json }) => {
        // dataURL is the exported image, json is the design
        console.log(dataURL, json);
      },
    });
  });
</script>
```

## Options

```javascript
function inchesToPx(inches) {
  var dpi = 72;
  return inches * dpi;
}

window.createYdesignEditor({
  key: 'YOUR_LICENSE_KEY',
  sections: [
    'templates',
    'photos',
    'text',
    'shapes',
    'upload',
    'background',
    'layers',
    'size',
  ],
  defaultSection: 'photos',
  width: inchesToPx(20),
  height: inchesToPx(10),
  // load a design from a URL
  jsonUrl: 'https://example.com/design.json',
  // or pass the design JSON; the script sends it after the studio is ready
  json: {
    // design JSON
  },
  publishLabel: 'Done',
  onPublish: ({ dataURL, json }) => {
    document.getElementById('result').src = dataURL;
    console.log('json', json);
  },
  onChange: ({ json }) => {
    console.log('json', json);
  },
  uploads: [
    {
      url: 'https://example.com/image.jpg',
      preview: 'https://example.com/image.jpg',
    },
  ],
  translations: {
    sidePanel: {
      templates: 'Templates',
    },
  },
});
```

`createYdesignEditor` returns `{ destroy }`, so you can close the dialog yourself. Clicking the backdrop closes it too.
