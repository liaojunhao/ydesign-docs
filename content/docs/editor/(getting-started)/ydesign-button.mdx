title: ydesign Button

**ydesign Button** embeds the editor into any website with one script. A button on the page opens the editor so people can design inside your app.

## Why use the ydesign button?

1. **Easier designing:** The ydesign UI lets people who are not design-tool experts make a complete design. Put the button in your app and they can start there.
2. **Light integration:** You do not rebuild an editor. Add the script and a button.
3. **No extra design tool:** People finish the design on your site instead of leaving for another platform.
4. **More time on site:** Creating and editing designs in place keeps people in your product longer.

## How to integrate

1. Add the stylesheet and the bundle. The files are `style.css` and `react-editor.bundle.js`. The URLs below use unpkg. You can host those two files on your own CDN and replace the URLs.

```html
<link
  href="https://unpkg.com/@ydesign/react-editor@0.8.2/dist/style.css"
  rel="stylesheet"
/>
<script src="https://unpkg.com/@ydesign/react-editor@0.8.2/dist/react-editor.bundle.js"></script>
```

2. Add a button and a mount container.

```html
<button id="ydesign-button">Open editor</button>
<div id="ydesign-editor" style="width: 100vw; height: 100vh"></div>
```

3. Open the editor when the button is clicked. Pass your license key.

```html
<script>
  const button = document.getElementById('ydesign-button');
  button.addEventListener('click', () => {
    const { createDesignEditorApp } = window.YDesignEditor;

    const { store } = createDesignEditorApp({
      // create your own license key at https://ydesign.com/cabinet/
      key: 'YOUR_LICENSE_KEY',
      container: document.getElementById('ydesign-editor'),
    });
  });
</script>
```

`createDemoApp` is an alias of `createDesignEditorApp`.

## Options

`createDesignEditorApp` takes `key`, `container`, and `sections`. Canvas size, design data, and saving go through the returned `store`.

```javascript
function inchesToPx(inches) {
  var dpi = 72;
  return inches * dpi;
}

const { store } = window.YDesignEditor.createDesignEditorApp({
  key: 'YOUR_LICENSE_KEY',
  container: document.getElementById('ydesign-editor'),
  // side panels to show; omit this to use the defaults
  sections: [
    'templates',
    'photos',
    'text',
    'shapes',
    'upload',
    'background',
    'layers',
    'size',
  ],
});

// panel to open first
store.openSidePanel('photos');

// initial canvas size, in pixels
store.setSize({
  width: inchesToPx(20),
  height: inchesToPx(10),
});

// load a design from a JSON object
store.loadJSON({
  // design JSON
});

// read JSON whenever the design changes, and save it yourself so loadJSON can restore it
store.on('change', () => {
  const json = store.toJSON();
  console.log('json', json);
});

// save from your own button. This returns the image and the design JSON
async function publish() {
  const dataURL = await store.toDataURL();
  const json = store.toJSON();
  document.getElementById('result').src = dataURL;
  console.log('json', json);
}
```
