**@ydesign/vue-editor** 是直接基于 Vue 的编辑器包，目前还在开发中。

它不把 React 编辑器嵌进 Vue，也不依赖 React 的编译。安装方式和组件示例会在包可用之后补上。

在此之前，可以用这些方式接入：

- React：[`@ydesign/react-editor`](/docs/editor/overview)
- 无框架脚本：[无框架集成](/docs/editor/frameworkless-integration)
- 按钮弹窗：[ydesign 按钮](/docs/editor/ydesign-button)
