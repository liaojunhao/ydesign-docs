**ydesign 按钮**用一段脚本把编辑器嵌进任意网站。页面上放一个按钮，点击后以弹窗打开编辑器，用户在你的应用里完成设计。

脚本地址：[https://static.yitu-design.com/button-v1.js](https://static.yitu-design.com/button-v1.js)。它会打开 `https://yitu-design.com/studio`，并通过 `postMessage` 把导出结果交回当前页面。

## 为什么使用 ydesign 按钮？

1. **降低设计门槛：** ydesign 的界面让不熟悉专业设计软件的人也能做出完整的设计。把按钮放进你的应用，用户就可以直接开始设计。
2. **接入简单：** 不需要重写一套编辑器，引入脚本并放一个按钮即可。
3. **省掉外部工具：** 用户在你的网站里完成设计，不必再跳到别的设计平台。
4. **提高停留：** 用户能在站内创建和修改设计，使用时间会更长。

## 如何接入？

1. 引入脚本。

```html
<script src="https://static.yitu-design.com/button-v1.js"></script>
```

2. 在页面上放一个按钮。

```html
<button id="ydesign-button">打开编辑器</button>
```

3. 点击时调用 `createYdesignEditor`。

```html
<script>
  const button = document.getElementById('ydesign-button');
  button.addEventListener('click', () => {
    window.createYdesignEditor({
      // 到 https://ydesign.com/cabinet/ 申请你自己的 License Key
      key: 'YOUR_LICENSE_KEY',
      onPublish: ({ dataURL, json }) => {
        // dataURL 是导出的图片，json 是设计数据
        console.log(dataURL, json);
      },
    });
  });
</script>
```

## 配置项

```javascript
function inchesToPx(inches) {
  var dpi = 72;
  return inches * dpi;
}

window.createYdesignEditor({
  key: 'YOUR_LICENSE_KEY',
  sections: [
    'templates',
    'photos',
    'text',
    'shapes',
    'upload',
    'background',
    'layers',
    'size',
  ],
  defaultSection: 'photos',
  width: inchesToPx(20),
  height: inchesToPx(10),
  // 从 URL 载入设计
  jsonUrl: 'https://example.com/design.json',
  // 或者直接传入设计 JSON，脚本会在编辑器就绪后发给 studio
  json: {
    // 设计稿的 JSON
  },
  publishLabel: '完成',
  onPublish: ({ dataURL, json }) => {
    document.getElementById('result').src = dataURL;
    console.log('json', json);
  },
  onChange: ({ json }) => {
    console.log('json', json);
  },
  uploads: [
    {
      url: 'https://example.com/image.jpg',
      preview: 'https://example.com/image.jpg',
    },
  ],
  translations: {
    sidePanel: {
      templates: '模板',
    },
  },
});
```

`createYdesignEditor` 返回 `{ destroy }`，可以主动关掉弹窗。点击遮罩也会关闭。
