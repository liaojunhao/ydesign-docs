**ydesign 按钮**用一段脚本把编辑器嵌进任意网站。页面上放一个按钮，用户点开就能在你的应用里做设计。

## 为什么使用 ydesign 按钮？

1. **降低设计门槛：** ydesign 的界面让不熟悉专业设计软件的人也能做出完整的设计。把按钮放进你的应用，用户就可以直接开始设计。
2. **接入简单：** 不需要重写一套编辑器，引入脚本并放一个按钮即可。
3. **省掉外部工具：** 用户在你的网站里完成设计，不必再跳到别的设计平台。
4. **提高停留：** 用户能在站内创建和修改设计，使用时间会更长。

## 如何接入？

1. 引入样式和打包脚本。产物是 `react-editor.bundle.js` 和 `style.css`。下面用 unpkg 上的地址；你也可以把这两个文件放到自己的 CDN，再换成自己的域名。

```html
<link
  href="https://unpkg.com/@ydesign/react-editor@0.8.2/dist/style.css"
  rel="stylesheet"
/>
<script src="https://unpkg.com/@ydesign/react-editor@0.8.2/dist/react-editor.bundle.js"></script>
```

2. 在页面上放一个按钮和挂载容器。

```html
<button id="ydesign-button">打开编辑器</button>
<div id="ydesign-editor" style="width: 100vw; height: 100vh"></div>
```

3. 点击按钮时，用 License Key 打开编辑器。

```html
<script>
  const button = document.getElementById('ydesign-button');
  button.addEventListener('click', () => {
    const { createDesignEditorApp } = window.YDesignEditor;

    const { store } = createDesignEditorApp({
      // 到 https://ydesign.com/cabinet/ 申请你自己的 License Key
      key: 'YOUR_LICENSE_KEY',
      container: document.getElementById('ydesign-editor'),
    });

    // store 可以使用 Store API：/docs/store
  });
</script>
```

`createDemoApp` 是 `createDesignEditorApp` 的别名。

## 配置项

`createDesignEditorApp` 接受 `key`、`container` 和 `sections`。画布尺寸、设计数据和保存都走返回的 `store`。

```javascript
function inchesToPx(inches) {
  var dpi = 72;
  return inches * dpi;
}

const { store } = window.YDesignEditor.createDesignEditorApp({
  key: 'YOUR_LICENSE_KEY',
  container: document.getElementById('ydesign-editor'),
  // 要显示的侧边栏，不传则显示默认面板
  sections: [
    'templates',
    'photos',
    'text',
    'shapes',
    'upload',
    'background',
    'layers',
    'size',
  ],
});

// 默认打开的面板
store.openSidePanel('photos');

// 画布初始尺寸，单位是像素
store.setSize({
  width: inchesToPx(20),
  height: inchesToPx(10),
});

// 从 JSON 对象载入设计
store.loadJSON({
  // 设计稿的 JSON
});

// 设计有改动时取出 JSON，自行保存以便稍后 loadJSON 恢复
store.on('change', () => {
  const json = store.toJSON();
  console.log('json', json);
});

// 用你自己的按钮保存。返回图片和设计 JSON
async function publish() {
  const dataURL = await store.toDataURL();
  const json = store.toJSON();
  document.getElementById('result').src = dataURL;
  console.log('json', json);
}
```
