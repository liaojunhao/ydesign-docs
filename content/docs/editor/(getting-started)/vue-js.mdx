**@ydesign/vue-editor** is a Vue-native editor package. It is still in development.

It does not embed the React editor inside Vue, and it does not depend on the React compiler. Install steps and component examples will be added when the package is ready.

Until then, use one of these:

- React: [`@ydesign/react-editor`](/docs/editor/overview)
- A script with no framework: [Frameworkless integration](/docs/editor/frameworkless-integration)
- A button dialog: [ydesign Button](/docs/editor/ydesign-button)
